# Glass Chat - Інструкція з розгортання на Render

Повноцінний чат в реальному часі з Glass UI дизайном для розгортання на Render.

## 📋 Що потрібно

1. Акаунт на [GitHub](https://github.com)
2. Акаунт на [Render](https://render.com) (безкоштовний)
3. Всі файли з цього проекту

## 📁 Структура проекту

```
glass-chat/
├── package.json          # Залежності Node.js
├── server.js            # Backend сервер
├── public/
│   └── index.html       # Frontend додаток
└── README.md            # Ця інструкція
```

## 🚀 Покрокова інструкція

### Крок 1: Створіть GitHub репозиторій

1. Зайдіть на [GitHub](https://github.com)
2. Натисніть **"New repository"** (зелена кнопка)
3. Введіть назву: `glass-chat`
4. Виберіть **Public** (публічний)
5. Натисніть **"Create repository"**

### Крок 2: Завантажте файли на GitHub

**Варіант А: Через веб-інтерфейс GitHub**

1. На сторінці вашого нового репозиторію натисніть **"Add file"** → **"Upload files"**
2. Перетягніть всі файли:
   - `package.json`
   - `server.js`
   - `README.md`
3. Створіть папку `public`:
   - Натисніть **"Add file"** → **"Create new file"**
   - Введіть `public/index.html`
   - Вставте вміст файлу `index.html`
   - Натисніть **"Commit changes"**

**Варіант Б: Через Git командний рядок**

```bash
# Клонуйте ваш репозиторій
git clone https://github.com/YOUR_USERNAME/glass-chat.git
cd glass-chat

# Скопіюйте всі файли в цю папку

# Додайте файли
git add .
git commit -m "Initial commit"
git push origin main
```

### Крок 3: Підключіться до Render

1. Зайдіть на [Render](https://render.com)
2. Натисніть **"Sign Up"** або **"Get Started"**
3. Виберіть **"Sign up with GitHub"**
4. Авторизуйте Render для доступу до GitHub

### Крок 4: Створіть Web Service на Render

1. На Dashboard Render натисніть **"New +"** → **"Web Service"**
2. Знайдіть репозиторій `glass-chat` і натисніть **"Connect"**
3. Налаштуйте параметри:

**Основні налаштування:**
```
Name: glass-chat (або будь-яка назва)
Region: Frankfurt (EU Central) - найближче до України
Branch: main
Root Directory: (залиште порожнім)
Runtime: Node
Build Command: npm install
Start Command: npm start
```

**План:**
- Виберіть **"Free"** (безкоштовний)

4. Натисніть **"Create Web Service"**

### Крок 5: Очікуйте розгортання

1. Render почне автоматично встановлювати залежності і запускати додаток
2. Процес займе 2-5 хвилин
3. Ви побачите логи в реальному часі
4. Коли побачите статус **"Live"** зеленого кольору - все готово!

### Крок 6: Відкрийте ваш чат

1. Скопіюйте URL вашого додатку (буде виглядати як `https://glass-chat-xxxx.onrender.com`)
2. Відкрийте його в браузері
3. Введіть своє ім'я
4. Почніть чатитися!

## ⚙️ Налаштування (опціонально)

### Змінити порт (якщо потрібно)

Render автоматично використовує змінну `process.env.PORT`, тому нічого міняти не потрібно.

### Додати власний домен

1. У Render перейдіть до Settings вашого сервісу
2. Натисніть **"Add Custom Domain"**
3. Введіть ваш домен і слідуйте інструкціям

## 🐛 Вирішення проблем

### Сервіс не запускається

1. Перевірте логи в Render Dashboard
2. Переконайтеся, що всі файли завантажені правильно
3. Перевірте, що `package.json` містить правильні залежності

### Чат не підключається

1. Перевірте, чи сервіс має статус "Live"
2. Відкрийте консоль браузера (F12) і перевірте помилки
3. Переконайтеся, що ви відкриваєте HTTPS версію сайту

### Сервіс засинає

Безкоштовний план Render засинає після 15 хвилин неактивності. При відкритті сайту він автоматично прокидається (займає ~30 секунд).

Щоб цього уникнути:
- Оновіться до платного плану ($7/місяць)
- Або використовуйте сервіс типу [UptimeRobot](https://uptimerobot.com) для періодичного пінгу
